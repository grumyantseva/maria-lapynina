# Мария Лапынина — прототип
Адаптивная страница на HTML, CSS и JavaScript без зависимостей.

Запуск из `/workspace/maria-lapynina`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Фотографии временные, загружаются с Unsplash. Для точного соответствия макету замените их оригиналами. Меню и форма выбора программы работают. Форма демонстрационная: данные не сохраняет и не отправляет, оплаты нет. Раздел результатов ожидает реальных материалов.
