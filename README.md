# Мария Лапынина — прототип
Адаптивная страница на HTML, CSS и JavaScript без зависимостей.

Запуск из `/workspace/maria-lapynina`:

```sh
python3 -m http.server 3000 --bind 0.0.0.0
```

Первый блок и карточки программ используют оригинальные фотографии из assets в формате WebP. В разделе «Обо мне» пока остаётся временный портрет с Unsplash. Меню и форма выбора программы работают. Форма демонстрационная: данные не сохраняет и не отправляет, оплаты нет. Раздел результатов ожидает реальных материалов.
